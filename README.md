A tiny paper-trading bot for Solana hourly bars that beats buy-and-hold: it buys a dip only when the trend agrees (MACD above its signal line and CCI at or under -20), then exits the hour the trend turns, at +8% take-profit, or at -10% stop-loss — and sits in cash when nothing qualifies. Dev window: net PnL +210.55 USDC on $10,000 (buy-and-hold: -869.34 USDC), 40 trades, max drawdown 2.22%.

## Run it

```sh
node main.ts
```
